# LPHPFilter
This is an example of a High-pass and low-pass filter audio plugin made by the Juce framework.

### Run on Win:

- Download the Juce Framework on the official Site;
- Run the LPHPFilter.jucer File;
- Open the project with your IDE-compatible to the Projucer;
- Compile/Build the project;

### Run on another OS:
- Read the official documentation.
